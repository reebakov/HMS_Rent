# Заявки в Jira Service Desk

В «Моей аренде» у каждого ПК и виртуалки есть кнопка **«Сообщить о проблеме»**. Сотрудник описывает проблему →
в Service Desk создаётся заявка типа «Проблема» (`SD_REQUEST_TYPE_PROBLEM`) с данными ПК/ВМ, номером заказа и командой. Номер заявки и статус
видны прямо у ПК; по клику — переписка: публичные комментарии админов из Jira (обновляются сами) и поле для ответа.
Внутренние заметки агентов сотрудник не видит.

Возврат ПК на сайте автоматически создаёт заявку **«Возврат»** (`SD_REQUEST_TYPE_RETURN`) — её номер и статус видны в «Истории».
Бронь ПК создаёт заявку **«подготовить ПК»** с выбранной ОС, а форма **«Сборка по запросу»** в каталоге — заявку на сборку
(обе — тип `SD_REQUEST_TYPE_ORDER`, «Прочее»; `SD_PREPARE_ON_BOOKING=false` отключает заявку при брони).
Заявки видны всей команде-получателю.

## Настройка

1. Сервисная учётка в Jira — **агент** этого Service Desk (нужно, чтобы создавать заявки от имени сотрудников
   и читать комментарии). Personal Access Token → `SD_TOKEN` в `.env` (или `SD_USERNAME` и `SD_PASSWORD`).
   Номер Service Desk и типы заявок (`SD_SERVICE_DESK_ID`, `SD_REQUEST_TYPE_*`) берутся из адреса портала
   `…/desk/portal/<id>/create/<тип>`; значения по умолчанию — в `.env.example`. Применить `.env`: на проде
   `sudo ./scripts/deploy.sh --redeploy`, при разработке `docker compose up -d --force-recreate backend worker`.
2. Проверка: `docker compose exec backend python -m app.cli sd-check` (на проде — с `-f docker-compose.prod.yml`) —
   покажет поля обоих типов заявок.
   Портал заполняет **Тему (summary)** и **Описание (description)**. Если другие поля обязательны —
   сделайте их необязательными в настройках типа заявки (иначе Jira не примет заявку и покажет ошибку).
3. От чьего имени создаётся заявка и как устроена переписка — `docs/ARCHITECTURE.md`, раздел «Заявки в Jira
   Service Desk» (`SD_RAISE_ON_BEHALF`, `SD_RETURN_ON_RETURN` отключают эти режимы).

Открытая переписка на сайте обновляется раз в 15 секунд; статусы заявок обновляет worker (`docs/ARCHITECTURE.md`).
Без `SD_TOKEN` (или `SD_USERNAME` и `SD_PASSWORD`) кнопка «Сообщить о проблеме» скрыта.
